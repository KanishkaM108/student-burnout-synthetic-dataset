Student Burnout Synthetic Dataset

This repository contains a synthetic dataset created for academic research
on student burnout prediction using deep learning techniques.

Dataset Description:
The dataset simulates realistic academic and lifestyle behavior patterns
of college students while preserving privacy. No real student data is used.

Dataset Size:
- Total records: 3000
- Total features: 8

Features:
- attendance: Attendance percentage
- study_hours: Average study hours per day
- sleep_hours: Sleep duration in hours
- screen_time: Screen exposure per day (hours)
- assignment_load: Number of assignments per week
- exam_frequency: Number of exams per month
- social_interaction: Social interaction time per week (hours)

Target Variable:
- burnout_level
  0 = Low Burnout
  1 = Moderate Burnout
  2 = High Burnout

Data Generation:
The dataset is synthetically generated using statistical distributions
inspired by publicly available student stress and burnout datasets.
Feature interactions are designed to reflect realistic burnout patterns.

Usage:
This dataset is intended strictly for educational and research purposes.
